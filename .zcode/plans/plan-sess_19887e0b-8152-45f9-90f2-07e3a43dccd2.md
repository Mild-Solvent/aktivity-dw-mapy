## Architecture

```
Vue 3 SPA (static)  ──HTTP──▶  /api  (Serverless Functions, hold secrets)
  ▲                              │
  │ reads                        ├─▶ Vercel KV  : trails metadata, users, sessions
  │                              └─▶ Vercel Blob: GPX + preview + gallery images
  └─ (ISR/cached)
```

**Two stores because:**
- **Blob** = binaries (what it's built for).
- **KV** = structured metadata + auth. Atomic ops prevent concurrent-write races when 2 admins edit at once. (JSON-in-Blob works but races.)

Both are **one-click** in the Vercel dashboard (Upstash via marketplace, no separate account). Env vars auto-injected. "Make project, build, done."

## What replaces what

| Current (Supabase) | New (Vercel) |
|---|---|
| `@supabase/supabase-js` (`src/lib/supabase.js`) | `src/lib/api.js` — fetch wrapper to `/api/*` |
| `trails` table (JSONB payload) | KV hash `trails:<id>` + `trails:index` set |
| `user_roles` table | KV hash `users:<email>` → `{passwordHash, salt, role}` |
| Supabase Auth (email/pw) | Web Crypto **PBKDF2** (zero deps), random session token in KV, `httpOnly+Secure+SameSite=Strict` cookie |
| RLS + `is_trail_manager()`/`is_admin()` | Auth check inside each `/api/*` handler (server = gate; frontend checks advisory — same trust model as today) |
| Storage bucket `trail-files` (`{id}/track.gpx`) | Blob path `tracks/<id>/track.gpx` |
| Storage bucket `trail-photos` (preview + gallery) | Blob `tracks/<id>/preview-<ts>.webp`, `tracks/<id>/gallery-<ts>-<n>.webp` |
| `VITE_ADMIN_EMAILS` bootstrap | `ADMIN_BOOTSTRAP_EMAIL` server env (never in client bundle) |
| GitHub Pages + `404.html` hack + CNAME | `vercel.json` rewrites + custom domain in dashboard |

**Kept untouched:** all 7 Vue components, `src/styles/` CSS tree, `gpxMapCapture.js`, `imageCompressor.js`, PWA manifest, all copy/UX.

**`AdminAddTrail.vue`** is the keystone — its form layout, GPX-upload + preview-regenerate flow, manual-photo-override, gallery (≤5 imgs → WebP), and delete-on-edit all stay. Only the upload targets and the `saveAdminTrail` call change.

## Tradeoffs (acceptable, given clean-slate goal)
1. **No per-track SSG/OG meta** — current `generate-static-pages.js` is already inert; share-preview meta goes client-side (Google executes JS; some scrapers may not). Non-blocking; can add one OG-injection edge function later if needed.
2. **Self-hosted auth** — you own hashing/sessions (Web Crypto PBKDF2, no deps). No email-confirmation flow. Fine for a tiny admin-heavy user base.
3. **Orphaned Blob cleanup** — same gap as today (trail delete leaves files). I'll add `del()` to `DELETE /api/trails/[id]` to actually fix this (small bonus).

## Risks to watch
- **KV 30K req/mo cap** (Vercel KV) vs 500K (direct Upstash). Fine at current scale; helper written against `@upstash/redis` so the swap is trivial if traffic ever grows.
- **Serverless cold starts** ~200–500ms on first idle request. Fine for admin paths used a few times/week.
